# Travel Book Cover Asset Pack

This package extracts the core visual content from the travel-agency book cover concept.

## Files

- `reference/reference_full_cover.png` — full cover concept mockup.
- `crops/book_main_crop.png` — main clickable book crop.
- `crops/book_cover_close_crop.png` — tighter book cover crop.
- `crops/agency_background_crop.png` — travel agency background detail.
- `crops/desk_props_crop.png` — passport, brochure, pen area.
- `crops/globe_detail_crop.png` — globe/desk detail.
- `crops/left_brochure_crop.png` — travel brochure detail.
- `prompt/cover_interaction_prompt.md` — ready-to-use Codex/Figma prompt.
- `asset_manifest.json` — metadata and suggested usage.

## Suggested workflow

Upload this whole ZIP to Codex along with the first visualization screenshot. Ask Codex to use this landing page as the intro and transition into the first visualization after the book-opening animation.
